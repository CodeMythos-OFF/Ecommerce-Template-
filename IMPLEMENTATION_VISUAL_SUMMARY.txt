  🔧 HOW IT WORKS NOW
═══════════════════════════════════════════════════════════════════════════

  AUTHENTICATION FLOW:

    Main App
       ↓
       ├─ User lands on page
       │  │
       │  └─ GoogleAuthService initializes (Singleton)
       │     ├─ Loads script from accounts.google.com
       │     └─ Initializes window.google.accounts.id (once!)
       ↓
    Auth Component
       ↓
       ├─ Displays "Sign in with Google" button
       │  │
       │  └─ User clicks button  
       ↓
    Popup Opens
       ├─ Google login page in popup
       │  │
       │  └─ User signs in with Google
       │     Popup redirects to /auth-callback
       ↓
    AuthCallback Component (in popup)
       ├─ Receives auth code & state from Google
       │  │
       │  └─ Verifies state parameter (CSRF protection)
       │  └─ Sends code back to parent via postMessage
       │  └─ Popup closes
       ↓
    Auth Component (receives message)
       ├─ Gets auth code from popup
       │  │
       │  └─ Sends to backend: POST /api/auth/google/callback
       ↓
    Backend (Production)
       ├─ Exchanges auth code for Google tokens
       │  │
       │  └─ Extracts user info from ID token
       │  └─ Creates or updates user in database
       │  └─ Generates JWT token
       │  └─ Sends token back to client
       ↓
    Auth Component
       ├─ Receives JWT token
       │  │
       │  └─ Stores in sessionStorage
       │  └─ Updates logged-in state
       │  └─ Calls onSignInSuccess callback
       ↓
    User Logged In ✅
